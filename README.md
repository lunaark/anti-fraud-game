# 防骗市集 🛡️

**你能识破骗局吗？**

这是一个互动式教育游戏，帮助人们识别和避免网络诈骗套路。

## 功能特性

- 🎮 **多种诈骗场景**：游戏账号、在线课程、二手物品等
- 🎯 **实时反馈**：选择后立即获得风险提示和正确指导
- 📊 **评分系统**：根据你的判断和选择计算骗局识别能力
- 🎓 **学习模块**：每个场景都附带详细的风险分析和防骗建议
- 🌐 **响应式设计**：支持桌面和移动设备

## 诈骗类型

游戏覆盖以下常见诈骗套路：

### 1. 游戏账号转账诈骗 🎮
- 虚假托管系统
- 钓鱼链接
- 密保信息套取
- **防护策略**：走官方平台交易，不提供敏感信息

### 2. 在线课程大单诈骗 📚
- 批量采购诱惑
- 敏感信息获取
- 先交保证金骗局
- **防护策略**：大客户也走平台，不提供银行信息

### 3. 二手物品交易诈骗 📦
- 先发货后付款
- "多转款"退款骗局
- 私下转账脱离平台保护
- **防护策略**：坚持平台担保，只相信实际到账

## 快速开始

1. 打开 `index.html` 在浏览器中
2. 点击"开始挑战"进入游戏
3. 根据对话选择正确的应对方式
4. 获取评分和详细反馈

## 核心防骗原则

✅ 安全建议：
- 始终选择官方平台交易
- 交易前不提供账号密码、验证码、密保等敏感信息
- 不点击任何非官方链接
- 以实际到账为准，截图可伪造
- 异常情况直接举报

❌ 常见套路：
- "先验证再付款"
- "系统延迟，先退款"
- "多转了钱，帮忙退"
- "假客服威胁"
